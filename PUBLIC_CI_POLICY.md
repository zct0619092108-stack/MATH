# Public CI usage policy

This repository is **public**. Only upload material that is intentionally public.

- Allowed: Lean 4/Mathlib setup, general mathematical definitions, harmless test theorems, reusable non-sensitive code.
- Do **not** upload unpublished YSC research, private proof files, certificate archives, research logs, private data, access tokens or passwords.
- Deleting a file after a GitHub Actions run does **not** remove its history, publicly readable workflow logs or copies that others may have made.
- This workflow's build confirms only that the checked public test module compiles. It does not certify unpublished YSC theorems or independently certify global geometry proofs.
- Store private research source, reproducibility information, proofs and logs in access-controlled storage instead.

This branch is a disposable public CI pilot; it does not change either historical YSC repository.
